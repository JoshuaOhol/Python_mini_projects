# Python_mini_projects
Beginner Python projects demonstrating programming fundamentals and problem-solving.



A collection of beginner Python projects created while learning
Python programming fundamentals.

## Projects

### 1. Python Quiz Game
An interactive quiz program that accepts user answers,
checks them, and calculates the final score.

Concepts used:
- Variables
- Data types
- User input
- Conditional statements
- Loops
- Score calculation

### 2. Shopping Cart Program
A simple shopping cart application that allows users to
add items, manage quantities, and calculate the total cost.

Concepts used:
- Lists
- Variables
- Loops
- Conditional statements
- User input
- Arithmetic operations

### 3. Countdown Timer
A basic countdown timer that takes a value from the user
and displays the countdown.

Concepts used:
- User input
- Loops
- Conditional logic
- Time functionality

### 4. Compound Interest Calculator
A calculator that accepts principal, rate and time and
calculates compound interest and the resulting amount.

Concepts used:
- Variables
- User input
- Arithmetic operators
- Basic Python logic
